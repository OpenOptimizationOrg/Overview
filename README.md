# Optimization * Libraries
This page gives a basic overview of the repositories contained in the OpenOptimization Organization, as part of the Optimization * Libraries (O*L) project
The website is hosted here: https://openoptimizationorg.github.io/Overview/

## Links:

### OPL – Optimisation Problem Library

A benchmark suite of black-box optimization problems.

- [GitHub Repository](https://github.com/OpenOptimizationOrg/OPL)
- [GitHub Pages](https://openoptimizationorg.github.io/OPL/)
- [Submit a New Problem (Google Form)](https://docs.google.com/forms/d/e/1FAIpQLSehQp24AuFAH2j9jizDhq8K_BYgNGMKXWTMu6s-2RwEJrK59Q/viewform?usp=sharing)

### OAL – Optimisation Algorithm Library

A database of optimization algorithms.

- [GitHub Repository](https://github.com/OpenOptimizationOrg/OAL)
- [GitHub Pages](https://openoptimizationorg.github.io/OAL/)
- [Submit a New Algorithm (Google Form)](https://forms.gle/PET78x7uNna4rK1dA)

### OFL – Optimisation Feature Library

A database of feature extraction methods for black-box optimization problems

- [GitHub Repository](https://github.com/OpenOptimizationOrg/OFL)
- [GitHub Pages](https://openoptimizationorg.github.io/OFL/)
