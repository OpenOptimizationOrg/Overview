Optimization * Library

A collection of open-source libraries for black-box optimization.

  • OPL – Optimisation Problem Library

    A benchmark suite of black-box optimization problems.

    benchmark-suite optimization-problems black-box-optimization
    Website GitHub Repository
  • OAL – Optimisation Algorithm Library

    A library for optimization algorithms.

    optimization-algorithms black-box-optimization
    Website GitHub Repository
  • OFL – Optimisation Feature Library

    A library for feature extraction from black-box optimization problems.

    feature-extraction black-box-optimization optimization
    Website GitHub Repository
  • Overview

    Overview page of the OpenOptimization Organization (this page).
